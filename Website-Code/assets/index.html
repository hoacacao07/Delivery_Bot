What “working in simulation” means

The actual CV model reads rendered images. The shared Pi policy makes navigation decisions. The compiled ESP32 firmware reads virtual sensor signals and controls four physics-driven wheels. GPS and cellular behavior are fixtures; radio coverage, real power, thermals, sensor calibration and campus positioning are not verified here.

The normal GNSS fixture is deliberately optimistic so route software can be tested. The 3 m uncertainty test demonstrates why uncorrected GPS alone may be insufficient to keep a small robot on a narrow path.
